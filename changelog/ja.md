## BetterGameExperience 0.5.0: 最初の公開版

BetterGameExperience (BGE) は、ゲームのファイルの横に置く2つの DLL で Civilization VI: Gathering Storm の不具合を
修正し、動作を速くします。**ゲームのファイルは一切置き換えません**。そのため、Steam のファイル確認や
ゲームのアップデートで削除されません。DirectX 11 と DirectX 12、BBG、Better Spectator Mod、MPH に対応
しています。

すべての変更を以下に分類して示します。**[全プレイヤー]** と記した変更はゲームのルールを変えるもので、
ロビーの全人間プレイヤーが同じバージョンの BetterGameExperience を持っているときだけ有効になります。それ以外
は自分のPCだけに関わるもので、MOD を持たないプレイヤーとも安心して遊べます。

### インストールとアップデート
- インストーラー `BetterGameExperience.exe`: インストール、アップデート、修復、アンインストール。Steam
  ライブラリからゲームを見つけ、何かをコピーする前に、署名付きマニフェストと各ファイルの SHA-256 を
  確認します。
- ゲームのファイルの横に2つのファイルを追加します: `winmm.dll` と `BGD_GameCore_XP2.dll`。古い
  インストール (0.3.0 以前) は自動的に片付けます。別の MOD の `winmm.dll` を上書きすることはありません。
- メインメニュー (MPH のメニューを含む) でのアップデート通知。**アップデート**を押すとゲームを終了し、
  新しいバージョンをインストールして、ゲームの再起動を案内します。
- 今後のバージョンを試すためのインストーラーの「プレリリース」チェックボックス。ワンクリックで安定版に
  戻せます。
- ゲーム起動のたびにアップデートを確認する Steam 起動オプション (任意)。
- インストーラーは Better Balanced Game と同じ11言語に対応。Windows の言語に従い、ウィンドウ下部で
  別の言語を選べます。

### 設定
- ゲームのオプションに新しい **BetterGameExperience** タブ: アンインストールせずにすべてを無効にするメイン
  スイッチ、機能ごとの設定、既定で隠れている詳細オプション。再起動が必要な変更はその旨を表示します。
- 組み込みインターフェースMODの作者へのクレジット。
- ゲーム内のテキストはすべて Better Balanced Game の11言語で利用できます: 英語、フランス語、ドイツ語、
  スペイン語、イタリア語、日本語、韓国語、ポーランド語、ブラジルポルトガル語、ロシア語、簡体字中国語。

### マルチプレイ
- **ロビーでの確認**: 各PCが自分の BetterGameExperience のバージョンを伝え、ホストが全員分を判定します。
  `BGE -` で始まるチャットメッセージで、MOD がない人や別のバージョンの人がわかります。再接続にも対応
  しています。**[全プレイヤー]** の修正が有効なときに MOD なしで参加した人がいると、ホストに警告が
  出ます。
- `BGE -` のチャットメッセージは英語で送られるので、MOD を持たないプレイヤーも読めます。MOD を持つ
  プレイヤーには、自分のゲームの言語で表示されます。
- **ゲームオプション「No First/Last moves (BGE)」** **[全プレイヤー]**:
  - 全プレイヤーが一緒にターンを開始します。全員の読み込みが終わるまで (最大60秒) 命令は保留され、
    タイマーも止まったままです。
  - ホストのタイマーが切れると、全員のターンが終わります。
  - MPH の旧来のターン同期は無効になります。
- MPH のロビーでのロードしたゲーム: 都市国家が原因で「無効なプレイヤーオプション」になり、準備完了
  ボタンが押せなくなる問題を解消しました。

### ゲームの修正 [全プレイヤー]
- 作業タイル: 2/2 のタイルが空いているのに、都市が 2/1 のタイルで働くことはなくなりました (食料と
  生産力を重視する場合)。
- Better Spectator Mod の観戦者は観光力に数えられなくなりました。世界会議で投票できず、決議の対象にも
  なりません。会議の画面は引き続き閲覧できます。
- 海洋ユニットは、都心だけでなく、あらゆる海洋区域 (港、ウォーターパーク、運河など) から都市へテレポートできます。都市から海洋区域へはすでにテレポートできたので、それと同じ扱いです (1タイルの湖に提督が閉じ込められることはもうありません)。

### インターフェースの修正
- 攻撃ボタン (都市、兵営、サイロからの核攻撃) をユニットの旗より手前に表示し、クリックできるように
  しました。
- 選択していない都市からの遠隔攻撃が、2回ではなく1回のクリックでできます。
- 都市や区域の遠隔攻撃の照準モードで敵ユニットの旗をクリックすると、そのユニットを攻撃します。
- 攻撃ボタンをクリックしてもカメラが移動しなくなりました (元に戻すこともできます)。
- 生産ターン数の表示に政府のボーナス (ファシズム、独裁政治、商業共和制) が反映されます。
- 2回の入れ替えで生産キューから外れた遺産を元に戻します。
- 別の都市に切り替えたとき、生産中の項目が正しく更新されます。
- 総督の行動や偉人の後に、上部バーの帝国の産出量が更新されます。
- *(実験的)* 外交画面が Esc メニューを閉じた後や、会議のポップアップが二重に出た後でも、キーボード
  ショートカットが使えなくなることはありません。
- Esc で使節の画面が正しく閉じるようになり、未配置の使節がターン終了を妨げなくなりました。
- *(実験的)* 都市を建設した後に開拓者レンズが再描画され、都市に近すぎるタイルは建設不可として表示
  されます。
- Enter は「次の行動」のキー設定に従います。そこから外して、別のショートカットに割り当てることもできます。Shift+Enter は引き続きターンを強制終了します。
- 敵の防衛可能な区域にいるユニットの移動範囲が表示されます。
- *(実験的)* 変化がないときはマップピンを再構築しないため、マルチプレイでの引っかかりが減りました。

### 組み込みインターフェースMOD
いずれも BetterGameExperience タブで無効にできます。Workshop の MOD も入れている場合は、BGE に組み込まれた版がそれに置き換わります。
- ユニットの旗に**労働者の残り回数** (Better Builder Charges Tracking、wltk 作に基づく)。
- 交易商の旗に**交易路の残りターン** (新機能)。
- **通知を消去**ボタン (NotificationClear、336tarot 作に基づく)。
- **拡張された上部バー**: 食料、生産力、人口、高級資源を都市ごとの詳細とともに表示 (TopPanel
  Extension Pro、号码菌 / Azukii 作に基づく)。
- **政策カードの効果**: 各カードに帝国にとっての実際の効果を表示 (Extended Policy Cards、Aristos 作に
  基づく)。Better Report Screen は不要になりました。次の値を修正しています:
  - ラージ、メディナ地区、修道制、市民の威信;
  - 徴兵、国民総動員令;
  - 近衛隊と植民地税のカード;
  - 偉人ポイント。[アイコン]+x の形で表示します。
- **改良されたレポート画面**: 取引、ユニット、政策、都市国家、都市のタブ付き (Better Report Screen、
  Infixo 作に基づく)。同じ修正を含みます。

### パフォーマンスと快適さ
- ターン処理の高速化:
  - 宣戦布告が連鎖する間、都市と外交の更新は一度だけ行います。計測したターンは2.4秒速くなりました (連鎖部分で −82%)。戦争中に都市国家が陣営を変えるときの重さが大幅に減ります。
  - 2つのキャッシュで AI のターンを高速化: 建設可能な施設とタイルの産出量。
  - 結果は元のゲームと同じなので、MOD を持たないプレイヤーとも安全です。
- クイック戦闘が有効なとき、核攻撃のアニメーションが20倍速くなります: 11秒ではなく約0.6秒。表示のみ。
- フレームレート制限に 45、75、90、100 FPS を追加しました。

### 既知の制限
- この MOD は現在の公式ゲームビルド向けです。ゲームがアップデートされると、BetterGameExperience が更新されるまで該当する機能は自動的に無効になります。
- **[全プレイヤー]** の修正が有効なときに MOD なしで途中参加したプレイヤーは、同期がずれます。ホスト
  には警告が出ます。
- *(実験的)* と記した修正は、まだ実際のゲームで試されていないか、効果がまだ十分に計測されていません。
- 英語とフランス語以外の翻訳は、まだネイティブスピーカーの確認を受けていません。修正の提案を歓迎
  します。
